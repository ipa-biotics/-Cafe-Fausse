# -Cafe-Fausse

A responsive, full-stack website for a restaurant. It provides information about the restaurant, displays the menu, allows customers to make table reservations, and showcases awards and customer testimonials.

## AI tools

These are the AI tools currently used for this project:

- **GPT-6.1 Sol** — AI assistant used for project planning, research, and problem-solving.
- **GitHub Copilot** — AI coding assistant used within GitHub to help with code, implementation, and development tasks.

This list reflects the tools currently in use and can be updated as the project’s AI tooling changes.
